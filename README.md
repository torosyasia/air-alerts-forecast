# air-alerts-forecast

Чи змінився режим повітряних тривог у Києві восени 2026 року, і як чесно прогнозувати
добові години тривоги, коли режим змінюється? Прогноз робимо для Києва, Харкова і Дніпра;
Львів — лише описове порівняння.

> Робота триває: повний README (результати, метод, обмеження) з'явиться на CP7.
> Рішення і їх обґрунтування — у [DECISIONS.md](DECISIONS.md), якість даних — у
> [reports/data_quality.md](reports/data_quality.md).

## Запуск
Python 3.13 (перевірено на 3.13.16), залежності з зафіксованими версіями — у `requirements.txt`.
Перший запуск завантажує ~45 МБ сирих даних із зафіксованих комітів і звіряє sha256
(`data/raw/MANIFEST.json`); у репозиторії лежить лише знімок KMDA.
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run_all.py           # усе: дані -> ціль -> ознаки -> baselines -> моделі -> звіти (~3 хв)
.venv/bin/python -m pytest            # тести на реальних даних, зокрема leakage-тести (~1.5 хв)
```
Окремі кроки: `python -m airalerts.build` (дані і ціль), `python -m airalerts.features`
(ознаки), `python -m airalerts.evaluate` (baselines), `python -m airalerts.models` (моделі).

## Режими (CP5): чи змінився режим у Києві
| Твердження | Доказ |
|---|---|
| У Києві є злам режиму, і він стався **27.08.2026** — до зміни правил 06.09 | Байєсівська точка зламу: MAP 27.08, HPD95 18–27.08 (години) і 26–27.08 (епізоди); P(злам до 06.09) = 1.000; log10 BF = 14 |
| Зросла насамперед **кількість** тривог | Епізодів 2.08 → 7.23 на добу (×3.5), години 1.70 → 8.04; ~80% зростання дала кількість, ~20% — тривалість |
| Тривоги розкидані **по всій добі** | Днів із тривогами в ≥3 з 4 шестигодинних блоків: 17% → 84% |
| Після реформи переважають **дронові** тривоги | Жовтих годин 91.6%, червоних 8.3%; у KMDA 168 з 170 дронових записів — «Дронова небезпека», лише 2 — «Масована» |
| Злам **цільовий**: різкий лише в Києві | Харків: чіткого зламу немає (log10 BF 0.9 / −1.3); Дніпро: дані за «без зламу» (log10 BF −1.6) |
| Навколо свят, переговорів і ударів по РФ тривог не більше | Перестановковий тест із локальними плацебо: жодне p < 0.05; Київ +0.13 год/добу [−0.26, +0.50] |

Обмеження: ми бачимо тривоги, а не дрони; «малі групи» — висновок із патерну. Деталі — у
[reports/regimes.md](reports/regimes.md), [reports/events.md](reports/events.md),
DECISIONS D-06a, D-19 і D-20.

## Поточний стан (CP4): тест 26.09–09.10.2026, 3 міста × 14 днів
| Метод | MAE, год | Покриття 80% | Ширина, год | Interval score |
|---|---|---|---|---|
| найкращий baseline за MAE (`climatology28`) | 3.55 | 0.86 | 12.08 | 17.16 |
| найкращий baseline за IS (`median7`) | 3.69 | 0.86 | 10.49 | 15.94 |
| **квантильна регресія, вся історія** (обрана на валідації) | **3.27** | 0.81 | 10.58 | **15.19** |
| квантильна регресія, свіже вікно 84 дні + CQR | 3.19 | 0.88 | 12.93 | 17.75 |

Модель краща за найкращий baseline за обома метриками, і її покриття близьке до 80%. Але
95% bootstrap-інтервали різниць містять 0 (MAE −0.28 [−0.67, +0.14], IS −0.75 [−3.67, +2.98]),
тож на 14 днях перевага статистично не доведена. По містах: Дніпро — краще за обома
метриками, Київ — тільки за IS (MAE 4.82 проти 4.30 у «вчора»), Харків — за жодною.
Деталі — у [reports/models.md](reports/models.md), обґрунтування — у DECISIONS D-17a і D-18.
Таблиці метрик — у `results/metrics_validation_test.csv`, ціль по днях — у
`results/daily_target.csv`.
